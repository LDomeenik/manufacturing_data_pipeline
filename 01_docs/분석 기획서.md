
# 생산관리 통합 분석 설계서

```
본 프로젝트는 Supply Chain, Manufacturing, Defect 데이터를 통합하여
주문 기반 생산관리 시스템을 데이터 파이프라인 형태로 설계하고,
재고 관리, 공정 스케줄링, 품질 분석까지 통합된 의사결정 시스템을 구축하는 것을 목표로 합니다.

단순한 데이터 분석을 넘어
주문 → 생산 → 공정 → 품질 → 납품까지 이어지는 생산관리 흐름을
하나의 시스템으로 모델링하고 자동화된 분석 환경을 구축합니다.

본 프로젝트는 다음과 같은 핵심 기능을 포함합니다.

- 주문 기반 재고 상태 분석
- 공정 스케줄링 최적화 (납기 기준)
- 불량률 예측 및 실제 결과 비교 (시뮬레이션)
- 불량 패턴 클러스터링 및 원인 분석
```


---

## 1. 문제 정의

```
생산관리 시스템에서는 주문, 재고, 공정, 품질 데이터가 분리되어 관리되는 경우가 많으며,
이로 인해 전체 생산 흐름을 통합적으로 분석하기 어려운 문제가 발생합니다.

특히 다음과 같은 한계가 존재합니다.

- 주문 기반 생산 계획 수립 어려움
- 공정 스케줄링 기준의 부재
- 재고 부족 및 납기 지연에 대한 사전 대응 부족
- 품질 데이터와 생산 데이터 간 연결 부족
- 데이터 기반 의사결정 체계 부재

따라서 본 프로젝트에서는 서로 다른 생산 관련 데이터를 통합하고,
전체 생산 흐름을 하나의 데이터 파이프라인으로 설계하여
운영 및 의사결정을 지원하는 시스템을 구축하고자 합니다.
```


---

## 2. 분석 목적 및 기대 효과

```
본 프로젝트의 목적은 생산관리 전 과정을 데이터 기반으로 통합하여,
재고 관리, 생산 계획, 공정 운영, 품질 분석까지 연결된 분석 환경을 구축하는 것입니다.

이를 통해 생산관리 전반에 대한 데이터 기반 의사결정 체계를 구축할 수 있으며,
다음과 같은 효과를 기대할 수 있습니다.

- 재고 최적화
- 생산 효율 향상
- 품질 개선
- 운영 자동화
```

- **분석 목표**
	- 주문 기반 생산 흐름 설계
	- 재고 부족 및 발주 필요 상태 분석
	- 납기 기준 공정 스케줄링 구현
	- 불량률 예측 모델 구축
	- 실제 생산 결과 기반 품질 비교 분석
	- 불량 패턴 클러스터링 및 원인 도출

- **기대 효과**
	- 재고 최적화
		- 재고 부족 사전 탐지 및 발주 의사결정 가능
	- 생산 효율 향상
		- 납기 기반 스케줄링을 통한 생산 흐름 최적화
	- 품질 개선
		- 불량률 예측 및 원인 분석을 통한 공정 개선
	- 운영 자동화
		- 주문 입력만으로 전체 분석 결과 도출 가능


---

## 3. 분석 범위 및 전제

```
본 프로젝트는 공개 데이터를 기반으로 작업하며, 
데이터의 한계로 일부 생산 관리 시스템을 시뮬레이션 형태로 구현합니다.

따라서 다음과 같은 전제 조건을 따릅니다.

- 실제 생산 시스템이 아닌 시뮬레이션 기반 모델
- 일부 데이터는 생성 데이터 사용
- 공정 흐름은 단순화된 형태로 구성
```

- **사용 데이터**
	- Supply Chain Dataset (재고, 수요, 리드타임)
		- https://www.kaggle.com/datasets/amirmotefaker/supply-chain-dataset
	- Manufacturing Dataset (공정, 생산 조건)
		- https://www.kaggle.com/datasets/ziya07/manufacturing-production-data
	- Predicting Manufacturing Defects Dataset (품질, 불량률)
		- https://www.kaggle.com/datasets/rabieelkharoua/predicting-manufacturing-defects-dataset

- **추가 생성 데이터**
	- Orders (주문 데이터)
	- Routing (공정 순서 데이터)
	- Production Log (생산 이벤트 데이터)
	- Delivery (납품 데이터)


---

## 4. 분석 Flow

```
본 프로젝트는 생산관리 흐름을 기준으로 파이프라인을 구성합니다.

세부적인 Flow는 다음과 같습니다.

주문 데이터 입력
→ 재고 상태 분석
→ 생산 계획 수립
→ 공정 스케줄링
→ 생산 이벤트 생성
→ 불량률 예측
→ 실제 생산 결과 생성
→ 납품 및 KPI 계산
→ 클러스터링 분석
```

## 5. 데이터 구조 설계


#### 5.1 Orders (생성)

```
order_id  
product_id  
order_qty  
order_date  
due_date  
priority
```

#### 5.2 Inventory (Supply Chain)

```
product_id  
inventory_level  
lead_time  
demand
```

#### 5.3 Production Plan (생성)

```
plan_id  
order_id  
product_id  
plan_qty  
planned_start_date
```

#### 5.4 Process (Manufacturing)

```
process_id  
machine_type  
process_time
```

#### 5.5 Routing (생성)

```
product_id  
process_sequence
```

#### 5.6 Production Log (생성)

```
product_id  
process_id  
start_time  
end_time  
qty
```

#### 5.7 Production Result (Defect 기반)

```
product_id  
process_id  
qty  
defect_qty
```

#### 5.8 Delivery (생성)

```
order_id  
shipped_date  
shipped_qty
```

## 6. 핵심 분석 모듈

```
본 프로젝트에서 활용할 핵심 분석 모듈은 다음과 같습니다.

- 재고 분석
- 공정 스케줄링
- 불량률 분석
- 클러스터링 분석
```

- **재고 분석**
	- 부족 재고 탐지
	- 안전 재고 이하 상품
	- 발주 필요 리스트

- **공정 스케줄링**
	- EDD (납기 기준) 스케줄링 적용
	- 공정별 시간 배정
	- 병목 공정 탐지

- **불량률 분석**
	- 머신러닝 기반 불량률 예측
	- 실제 생산 데이터와 비교

- **클러스터링 분석**
	- KMeans 기반 그룹화
	- 공정 조건별 불량 패턴 분석


---

## 7. 최종 Output

```
본 프로젝트의 최종 출력은 다음과 같습니다.

- 재고 상태
- 공정 스케줄링 결과
- 불량률 비교 결과
- 클러스터 분석 결과
```

- **재고 상태**
	- 부족 재고 리스트
	- 재고 상태 (정상 / 부족 / 위험)

- **공정 스케줄링 결과**

```
product_id | process_id | start_time | end_time
```

- **불량률 비교**

```
product_id | predicted_defect_rate | actual_defect_rate
```

- **클러스터 분석**
	- 고불량 그룹 특징
	- 공정 조건별 문제 원인
